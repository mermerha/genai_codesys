## D010：功能块候选必须进入主程序引用链

- 日期：2026-11-05
- 状态：已确定
- 决定：编译 `FUNCTION_BLOCK` 候选时，harness 在临时工程的 `PLC_PRG` 中自动创建实例并调用该功能块。
- 原因：实际验证发现，只有创建但未被引用的功能块即使包含未定义标识符，应用构建仍可能显示 0 错误；这种结果不能代表候选代码真正通过编译。
- 证据：未引用时包含 `MissingSignal` 的候选被报告为成功；加入 `PLC_PRG` 引用后，CODESYS 对 `MotorControl` 返回错误号 32 和 46，并准确给出对象和位置。

## D011：模型 B 候选改为 qwen3.8-flash

- 日期：2026-11-09
- 状态：已被 D012 替代
- 决定：按用户选择，将模型 B 由 `qwen3.5-flash` 改为 DMXAPI 模型 ID `qwen3.8-flash`，并固定使用 `reasoning_effort=none`。
- 原因：该模型默认高强度推理导致 `public_09` 在 300 秒内无输出；`low` 虽使 `public_09` 首次编译通过，但 `public_19` 仍在 300 秒超时。关闭思考后，三道不同难度预验证题均在 300 秒内完成：`public_03` 和 `public_19` 首次编译通过，`public_09` 经一次 JSON 解析修复后编译通过。
- 限制：这里只冻结模型身份和推理档位，不代表生成代码已通过功能测试。人工快速复核发现 `public_19` 候选在手动模式下可能同时输出相反方向命令，因此该次编译成功不能计为任务功能通过。
- 公平性：正式实验中，自研 harness 和现成 Agent 使用该模型时必须保持相同的 `reasoning_effort=none`；其他参数仍需在正式实验冻结前确定。

## D012：模型 B 暂定为 qwen3-coder-flash

- 日期：2026-11-09
- 状态：暂定
- 决定：按用户选择，模型 B 暂定为 DMXAPI 模型 ID `qwen3-coder-flash`，使用默认推理配置，不传 `reasoning_effort`。
- 依据：在简单题 `public_03` 上首次编译通过，人工核对未发现阈值、滞回或错误状态逻辑遗漏。模型生成及框架开销约 2.813 秒，原 `qwen3.8-flash` 同题约 3.266 秒。
- 后续验证：困难题 `public_19` 首次因错误使用 `EXIT` 编译失败，修复一次后编译通过；但最终代码要求新的 Start 上升沿才能继续每个步骤，单周期和连续模式不能自动完成，功能未通过。
- 限制：困难题默认配置候选虽然首次编译通过，但自动流程功能错误；编译成功不能视为任务通过。
- 后续对比：默认配置下，`qwen3.8-flash` 在 300 秒内无输出，`glm-5.3` 功能表现更好但更慢、更贵。用户决定暂不切换，继续以 `qwen3-coder-flash` 作为模型 B。
- 补充：`glm-5.3-flash` 默认配置在同一困难题上 300 秒无输出，不作为当前模型 B 推荐候选。
- 补充：`qwen3.8-omni-flash` 默认配置在同一困难题上 300 秒无输出，不作为当前模型 B 推荐候选。

## D018：现成 Agent 基线更换为 Codex CLI

- 日期：2026-11-09
- 状态：已确定
- 决定：因预跑中 `smolagents CodeAgent` 表现较差，按用户选择将现成 Agent 基线更换为本机 `Codex CLI 0.167.0-alpha.3.2`，仍使用与自研 harness 相同的两个 DMXAPI 模型和最多 3 个候选。
- 实现：每轮使用 `codex exec --json --output-schema` 生成四字段候选；Python 外部循环调用同一 CODESYS 编译器，并把上一候选和编译错误传给下一轮。编译通过后才运行共享测试，测试内容不反馈给 Agent。
- 兼容性：DMXAPI 的 Responses 接口支持单轮 Codex 调用，但不兼容 Codex CLI 工具回传所需的 `tool` 角色，因此不在 Codex 内部调用编译工具。该适配只移动编译反馈边界，不改变候选次数、模型、题目或判定标准。
- 验证：固定电机启停样例使用 `qwen3-coder-flash` 首次编译通过，共享测试 2/2 通过；保存 Codex JSONL 轨迹、最终候选、编译和测试证据。

## D019：正式实验仅重跑有明确基础设施故障的条件

- 日期：2026-11-10
- 状态：已确定
- 决定：模型生成、编译或功能测试本身的失败作为正式结果保留；只有存在明确外部故障证据时才重跑对应条件。本批次确认的外部故障包括 DMXAPI SSL 连接提前断开、Codex CLI 连续报告 stream connection failed，以及一次 CODESYS 测试执行器超时。

- 公平性：重跑不修改题目、提示词、模型、参数、候选次数或测试标准；不得仅因模型生成质量、编译失败或功能测试不通过而重跑。
