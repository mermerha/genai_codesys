# 配置目录

本目录保存开发和实验配置模板，以及被 `.gitignore` 排除的本机配置。

- 可共享模板使用明确的示例文件名，例如 `project.example.yaml`。
- 本机绝对路径和密钥不得写入共享配置；API Key 通过环境变量读取。
- 正式实验开始时，将实际使用的完整配置写入对应的 `experiments/raw/<run_id>/.../run_config.json`。
- 原始运行目录中的配置快照是该次实验的最终依据，不依赖之后可能变化的模板。

`experiment.json` 是当前四种设置的冻结配置；`pre_run_tasks` 只用于正式实验前的小规模预跑，正式阶段仍覆盖全部 30 道题。

`experiment_v2.json` 是后续 harness 改进配置，启用候选预检和重复错误重生成。它不追溯修改 `formal_v1` 原始结果；使用前只需做一次小规模预跑，确认后再决定是否建立新的正式批次。
